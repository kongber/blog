# 高频计算题

每年约 2～5 分。下面四类优先拿满；伏格尔运输题步骤长、分值低，时间不够可以放弃。

## 指派问题（匈牙利法，求最小工时）

1. 每行减去该行最小值。
2. 每列减去该列最小值。
3. 找不同行不同列的独立零。零的个数等于人数，就按这些零对应的原始工时相加。
4. 零不够：用最少直线盖住所有零；未盖住元素中的最小值，未盖住的减去它，交叉点加上它。再找独立零。

例：四人岗位行归约、列归约后得到独立零，对应原始工时 3+3+4+4=14。

## 最短路径（Dijkstra）

从起点开始，不断用「已经确定的最短距离 + 边权」去松弛邻居，只保留更小的。表或图都一样。运煤题要把装货费和卸货费加进对应结点，最后别漏卸货费。

## 最小生成树（优先 Kruskal）

边按权从小到大收，收了会成环就丢掉，直到 n−1 条边。村村通公路就是 MST。水管题若水库必须先接到最近的村，总长 = 这段主管 + 各村之间的 MST。

## 最大流

按费用从小到大选一条还能走的源到汇的路径，流量取路径上容量最小的那段，然后沿路减去这个流量，容量变 0 的边断开。直到没有路。总流量是各次流量之和，总费用是各次「流量 × 路径费用」之和。

也可以枚举割，割的容量取最小的那个，等于最大流。不是每一种算法步骤都取到同一个中间方案，但最大流的值应一致。

## 其他必会公式（分散在各章）

- 采样：n = α (z / e)²，α 默认 0.25，90% 时 z≈1.65
- 三点估算：(乐观 + 4×最可能 + 悲观) / 6
- 串联可靠性连乘；并联是 1 减「各自失效概率连乘」
- McCabe：E−N+2 或 P+1
- 流水线时间：首条各段之和 + (n−1)×最慢段
- 奈氏：2W log2 V；香农：W log2(1+S/N)
- 页式：物理地址 = 块号 × 页大小 + 页内偏移
- 补码范围：−2^(n−1) ～ 2^(n−1)−1
- 位示图字数 = (磁盘容量 / 块大小) / 字长
- 信号量 S<0 时，等待进程数 = |S|
