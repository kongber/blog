# 16. 法律法规（重点，每年 2～4 分）

知识产权四特点：无形、专有、地域、时间。相关法：著作权、软件保护条例、专利、商标、反不正当竞争。

思想、处理过程、算法、数学概念不受著作权保护。保护的是带业务逻辑的程序和文档。法律官方文件、时事新闻、历法、通用数表和公式不适用著作权法。作品完成即享有著作权，登记只为举证。绘画原件卖掉，著作权仍归作者，买主有物权和展览权。

**期限**

| 客体 | 期限 |
| --- | --- |
| 署名权、修改权、保护作品完整权 | 无限制 |
| 公民发表权、使用权、获酬权 | 终身 + 死后 50 年，截止第 50 年 12 月 31 日。合作软件以最后死亡者为准 |
| 单位作品发表、使用、获酬 | 首次发表后 50 年 |
| 注册商标 | 10 年，期满后 6 个月内必须续展。注册人死亡或倒闭 1 年未转移可注销 |
| 发明专利 | 20 年，从申请日 |
| 实用新型 | 10 年，从申请日 |
| 外观设计 | 15 年，从申请日 |
| 商业秘密 | 不固定，公开后公众可用。必须有保密措施才算 |

**职务作品归属给单位（署名权仍归作者）的典型情形**

- 主要利用单位物质技术条件，或合同约定归单位
- 软件：本职工作有明确开发目标、是本职活动的结果、使用单位资源且单位承担责任
- 专利：执行本单位任务，或主要利用单位条件；离职、退休、调动后 **1 年内**作出的与原单位工作相关的发明，仍算职务发明

委托创作默认归创作方，可以约定归委托方。合作开发共同享有。商标谁先申请谁拥有；同一天看谁先使用。专利谁先申请；同一天协商，不能同时驳回双方。

署名权不因离职消失。把开发者署名换成别人，侵犯署名权。

合理使用（不侵权）常见：个人学习、适当引用、教学科研、免费表演、室外公共场所艺术品的临摹拍摄、汉译少数民族语言或盲文。未许可发表、占合作作品为己有、没参与却署名、歪曲篡改、剽窃、该付酬不付、擅自用别人的版式，都是侵权。

专利三性：新颖、创造、实用。外观设计要与已发表的不相同也不相近似。

不授予专利：科学发现、智力活动规则和方法、疾病诊断和治疗方法、动植物品种、原子核变换得到的物质。

不视为侵权：权利用尽（售出后的使用）、申请日前已在制造的原范围继续、外国运输工具临时过境、专为科学研究和实验。
