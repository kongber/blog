# 12. 计算机网络（次重点，设备和公式是重点）

传输：单工（广播）、半双工（对讲机）、全双工（电话、交换式以太网）。

码元：一个波形状态。V 进制码元携带 log2(V) 比特。

- 奈氏（无噪声）：最高码元速率 2W；极限数据率 = 2W × log2(V)
- 香农（有噪声）：C = W × log2(1 + S/N)。S/N 是线性比，不是 dB。dB = 10×log10(S/N)。实际速率低于 C 才可能无差错

模拟调制：调幅 ASK 简单易扰，调频 FSK 抗扰较好，调相 PSK 抗扰强、实现复杂。

数字编码：不归零难同步；曼彻斯特每比特中间跳变，既是时钟也是数据，效率只有一半；差分曼彻斯特中间跳变只做同步，比特起点有无跳变表示数据；4B/5B 用 5 位表示 4 位，解决波特率过高。

CRC：生成多项式按系数写成二进制；信息码后补「最高次数」个 0；模 2 除（异或）；余数就是校验码。

**OSI 与协议归属（按「协议在哪一层」考，不按背层次定义考）**

| 层 | 协议 |
| --- | --- |
| 应用 | HTTP、FTP、SMTP、POP3、DNS、Telnet、SNMP |
| 表示 | SSL/TLS |
| 会话 | NetBIOS、RPC |
| 传输 | TCP、UDP |
| 网络 | IP、ICMP、IGMP、ARP、RARP |
| 链路 | PPP、HDLC、Ethernet、VLAN、MAC |
| 物理 | RS-232、RJ-45、802.3 |

口诀：物联网书会使用。TCP/IP 四层口诀：应传网接。ARP 在软考网络层（有的资料放链路层，按本书答网络层）。

**端口（TCP 还是 UDP 一起记）**

| 协议 | 端口 | 传输层 |
| --- | --- | --- |
| FTP | 21 控制，20 数据 | TCP |
| Telnet | 23 | TCP |
| SMTP | 25 / 587，加密 465 | TCP |
| HTTP | 80 | TCP |
| POP3 | 110，加密 995 | TCP |
| IMAP | 143，加密 993 | TCP |
| DNS | 53 | 主要 UDP（区域传送可用 TCP，选择通常认 UDP） |
| DHCP | 67 服务器，68 客户端 | UDP |
| TFTP | 69 | UDP |
| SNMP | 161 管理，162 陷阱 | UDP |

POP3 下载到本地，多设备同步弱；IMAP 邮件留在服务器，多设备同步。

TCP：面向连接、可靠、全双工、重发。UDP：无连接、快、检错弱。书上的场景记忆：数据少且要可靠用 TCP；数据量大、能容忍不可靠、要速度用 UDP。

IP 分类：A 0～127，B 128～191，C 192～223，D 224～239 组播，E 240～255 保留。

- 网络地址：主机位全 0
- 广播地址：主机位全 1
- 回环：127.0.0.1，不出主机
- 两台机器是否同网：各自 IP 与掩码按位与，结果相同则同网
- CIDR：IP/前缀长度。再划分 2^k 个子网就再借 k 位。路由器多条都匹配时用**最长前缀**

IPv6：128 位、冒号十六进制、报头固定 40 字节、无校验和、分片在源端、强制 IPsec、不必靠 NAT、SLAAC 自动配置。

局域网拓扑：星形怕中心挂；总线怕干线断；环形单点可能断环；网状贵、实际少用。

以太网 CSMA/CD：先听后发，边发边听。非坚持（忙就随机等）、1-坚持（忙就一直听，空了马上发，利用率高易撞）、P-坚持（空闲以概率 P 发）。

Wi-Fi 速率量级：4 是 n、约 600 Mb/s；5 是 ac、约 6.9 Gb/s；6 是 ax、约 9.6 Gb/s；7 是 be、约 46 Gb/s。频段：b/g 只有 2.4，a/ac 偏 5，n/ax/be 多频段，be 含 6 GHz。

**设备工作层次（重点）**

| 设备 | 层 |
| --- | --- |
| 中继器、集线器 | 物理层。集线器是多端口中继器。以太网中继器最多约 4 个 |
| 网桥、二层交换机 | 数据链路层，看 MAC。二层交换机是多端口网桥 |
| 路由器、三层交换机 | 网络层，看 IP。三层交换机是带路由的二层交换机 |
| 网关 | 传输层及以上，协议转换 |

交换：电路交换独占通路；报文交换存储转发、难实时；分组交换最常用，分数据报和虚电路。

路由协议：内部 RIP、OSPF、IGRP、EIGRP；外部 BGP。算法上：距离向量定期发整表；链路状态发链路状态、各自算最短路。

网络工程三阶段：规划（需求、可行性、现状）→ 设计（目标、子网、设备、安全）→ 实施（计划、验收、安装、测试、试运行、培训、转换）。
