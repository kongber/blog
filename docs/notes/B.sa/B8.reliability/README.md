# 8. 系统可靠性（次重点，定量是重点）

可靠性：规定条件、规定时间、完成规定功能的能力。规定时间最好用 CPU 执行时间度量。

设计手段（论文用）：恢复块、N 版本程序、冗余、检错、降低复杂度、双机热备、服务器集群。

可靠度 R(t) = 1 − F(t)。F(0)=0，F(∞)→1；R(0)=1，R(∞)=0。

五因素：运行剖面（环境）、规模、内部结构、开发方法与环境、可靠性投入。口诀：还闺内发钱。

**McCabe 环形复杂度**（三法结果相同）

- V(G) = 线性无关区域数（含图外面的那一块）
- V(G) = E − N + 2
- V(G) = P + 1，P 是判定结点数

**串并联（必会）**

- 串联：一个坏全坏。R = R1 × R2 × … × Rn
- 并联：全坏才坏。R = 1 − (1−R1)(1−R2)…(1−Rn)
- 混联：先算局部串或并，再代入。
