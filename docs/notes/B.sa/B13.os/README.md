# 13. 操作系统（次重点，内存和 PV 是重点）

进程是资源分配的基本单位，**线程是调度的基本单位**。

三态：就绪、运行、阻塞。口诀：舅运祖。

- 就绪：资源齐了，只等 CPU
- 运行：占着 CPU。单 CPU 同时只有一个
- 阻塞：等 I/O 或别的事件，给 CPU 也跑不了

五态再加新建、终止。

同步是讲究先后顺序（读写管道）；互斥是独占临界资源（打印机）。

**PV**

- P：S = S−1。减完 ≥0 继续；<0 阻塞。绝对值 |S| 在 S<0 时就是等待进程数
- V：S = S+1。加完 >0 继续；≤0 则唤醒一个阻塞进程

前趋图只画直接前驱，不能把间接关系也画成边。解题：前驱结束处 V，后继开始处 P。初值常为 0。

死锁四条件：互斥、不剥夺、请求并保持、环路。预防就是破坏其中一条。

**页式（必会算）**

逻辑地址 = 页号 + 页内地址。页内位数 = log2(页大小)。物理地址 = 物理块号 × 页大小 + 页内地址。

例：64 KB 空间、1 KB 页 → 逻辑地址 16 位，页号 6 位，页内 10 位。

段式：段号 + 段内地址，段长可变，段间不要求连续。

虚拟存储：不用一次装入，缺页再调，满了再置换。

置换：FIFO 淘汰最早进入的；LRU 淘汰最久没用的；OPT 淘汰将来最晚用到的（理想、用来做参照）；Clock 用访问位转圈找 0。

文件索引：直接地址覆盖前几个逻辑块；一级间接一块能放「块大小/地址项长度」个块号；二级是这个数的平方。先算每一级的逻辑块号区间，再判断题目给的块号落在哪一级。

位示图：物理块数 = 容量 / 块大小；字数 = 物理块数 / 字长。例：300 GB、4 MB 块、32 位字 → 76800/32 = 2400 字。
