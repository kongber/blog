# 11. 计算机组成原理（次重点，流水线是重点）

层次从低到高：硬联逻辑 → 微程序 → 传统机器（指令集）→ 操作系统 → 汇编 → 高级语言 → 应用语言。

Flynn：SISD 传统单机，SIMD 阵列机，MISD 少见（流水线有时被这么叫），MIMD 多机 / 超算。记住两头：SS 单机，MM 服务器。

冯·诺依曼：存储程序，程序和数据放同一存储器。五部件加外存：运算器、控制器（两者合成 CPU）、主存、输入、输出。数据流经主存，控制流由控制器发出。

**原码、反码、补码（8 位，以 −5 为例）**

- 原码：10000101。+0 和 −0 两个零。加减要看符号，硬件麻烦。
- 反码：符号位不变，数值位取反 → 11111010。仍有两个零。
- 补码：反码加 1 → 11111011。零唯一。减法变加法。
- n 位补码范围：−2^(n−1) ～ 2^(n−1)−1。8 位是 −128～127。多出来的那个是 10000000 = −128。

定点数：小数点位置约定好，不存进机器。浮点数：符号 + 阶码 + 尾数（或阶符 + 阶码 + 数符 + 尾数）。**阶码决定范围，尾数决定精度**。0.1 不能有限二进制精确表示，所以 0.1+0.2≠0.3。

存储速度：寄存器 > Cache > 主存 > 辅存。CPU 不能直接访问辅存。Cache 依据是局部性：

- 时间局部性：刚用过的很快再用（循环）
- 空间局部性：邻近单元很快被用（顺序执行、数组）

平均访问时间按命中率加权。若 1/5 指令还要额外访存一次操作数，总时间 = 取指时间 + (1/5)×取数时间。

Cache 映射：

| 方式 | 主存块能放哪 | 地址字段 |
| --- | --- | --- |
| 直接 | 只能放固定一行。行号 = 块号 mod 行数 | 标记 + 行号 + 块内偏移 |
| 全相联 | 任意行。冲突少，比较器多 | 标记 + 块内偏移 |
| 组相联 | 只能进固定组，组内任意行。组号 = 块号 mod 组数 | 标记 + 组号 + 块内偏移 |

E 路组相联：每组 E 行。组数 S = 行数 / E。块内偏移位数 = log2(块大小)。

RAID：0 无冗余最快，利用率 100%；1 镜像，坏 1 块，利用率 50%；5 至少 3 盘，1 份奇偶，坏 1 块，利用率 (N−1)/N，写要写校验；6 至少 4 盘，两份校验，坏 2 块；10 先镜后条或条加镜，两组里各坏一个，利用率 50%。

磁盘：先移臂再旋转。SSTF 每次选离当前柱面最近的请求；同柱面按扇区顺序，不要把顺序反过来。

I/O 五方式：程序控制、程序中断、DMA（主存与外设之间批量交换，CPU 少插手）、通道、I/O 处理机。

存储连接：DAS 直连服务器；NAS 走网络、文件级；SAN 专用网、块级。

总线：同一时刻只许一个部件发送，多个可以同时接收。带宽 = 总线宽度 × 总线频率。若一个总线周期占 2 个时钟，总线频率 = 时钟频率 / 2。例：4 字节、10 MHz 时钟、2 时钟为一周期 → 5 MHz × 4 B = 20 MB/s。

CISC：指令多、变长、微程序控制。RISC：指令少、定长、单周期、只有 Load/Store 访存、硬布线、通用寄存器多、适合流水线。

**流水线公式**

- 执行时间 = 第一条指令各段时间之和 + (指令数 − 1) × 最慢那段的时间
- 吞吐率 TP = n / Tk
- 最大吞吐率 = 1 / max(ti)
- 加速比 S = 顺序时间 T0 / 流水时间 Tk
- 度为 m 的超标量：近似当成 m 条流水线分摊指令条数

阿姆达尔：被加速部分占比 f，加速 k 倍。整体加速比 = 1 / ((1−f) + f/k)。例：50% 加快 10 倍 → 1 / (0.5 + 0.05) ≈ 1.818。

基准程序准确度：真实程序 > 核心程序 > 小型基准 > 合成基准。
