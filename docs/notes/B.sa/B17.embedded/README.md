# 17. 嵌入式系统（次重点，概念要能选）

定义：以应用为中心、可裁剪、软硬件可配置的专用计算机。设计时同时权衡功能、可靠性、成本、体积、功耗。

五特点：专用性强、实时性强、资源受限、软硬件依赖强、对用户透明（用户只看到设备功能）。

层次：硬件层（处理器、SDRAM/ROM/Flash、I/O、电源时钟复位）→ BSP/HAL（屏蔽硬件差异）→ 系统软件层（RTOS、文件系统、GUI、协议栈、嵌入式数据库）→ 应用层。

嵌入式数据库四特点：嵌入性（不是独立大服务器）、实时性、移动性（要能离线再同步）、伸缩性（能裁剪）。组成：设备上的嵌入式数据库、同步服务器、主数据库服务器、连接网络。

操作系统分类：

- 硬实时：错过截止时间就算失败。制动、飞控、工业保护
- 软实时：偶尔超时只是体验变差。手机卡顿、视频掉帧

内核：宏内核服务都在内核里，快但耦合高；微内核只留最小调度、内存和通信，其余在用户态，隔离好但消息开销大；混合内核把性能敏感的服务放回内核。

调度：

- 优先级抢占：永远跑就绪队列里优先级最高的。静态优先级创建时定死；动态可按截止时间改
- 时间片轮转：同优先级之间。片太大退化为顺序执行，片太小切换开销大。实际常用「优先级抢占 + 同级轮转」
- RMS：周期越短优先级越高。静态
- EDF：截止时间越近优先级越高。动态，理论利用率可达 100%，开销大
- 分区调度：固定时间窗口，时间隔离，静态确定。航空电子

CPS：感知 → 分析 → 决策 → 执行。

| 级别 | 组成 | 例子 |
| --- | --- | --- |
| 单元级 | 硬件 + 软件 | 智能轴承、一台智能机床 |
| 系统级 | 再加网络 | 智能产线、SCADA |
| SoS 级 | 再加平台 | 工业互联网平台、智慧城市 |

差别不在设备大小，而在有没有网络、有没有跨系统平台。
