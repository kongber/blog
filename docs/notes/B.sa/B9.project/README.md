# 9. 项目管理（次重点，进度是重点）

范围五过程（教材没有 PMBOK 的「收集需求」）：编范围管理计划、定义范围、创建 WBS、确认范围、范围控制。

进度六过程：活动定义、排序、资源估算、历时估算、计划编制、控制。

- 单代号 AOV：结点是活动
- 双代号 AOE：结点是事件，箭线是活动。软考求工期优先用双代号
- 关键路径：最长的那条，其上总时差为 0
- 资源受限时，关键路径算出的工期还要被人数再撑长

**三点估算**：期望 =（乐观 + 4×最可能 + 悲观）/ 6

成本三过程：估算（自顶向下、自底向上、差别估算）、预算（分到工作包，形成成本基准）、控制。

配置管理：编计划、配置标识、变更控制、状态报告、配置审核。

风险六过程：计划编制、识别、定性分析、定量分析、应对、监控。消极风险：避免、转移、减轻。积极风险：开拓、分享、提高。定量分析工具：灵敏度、期望货币价值、决策树、蒙特卡罗。
